### 🚀 Sobre mí

Desarrollador de software enfocado en construir **aplicaciones web modernas** y **pipelines de automatización inteligente** que resuelven problemas reales de negocio, combinando **IA Multimodal** con **ingeniería determinística**:

- 🤖 **Arquitecturas Híbridas IA + Código Determinístico (InsurTech):** Flujos *Human-in-the-Loop* que combinan visión/lenguaje con validación estricta en **Python** (*zero-hallucination*, auditoría documental a doble ciego, relevamiento geoespacial y generación automatizada de informes `.docx`/`.html`).
- 🎬 **Video Programático & Automatización Creativa (*Video-as-Code*):** Motores de producción publicitaria en **Remotion v4 + FFmpeg + Zod** para generar variaciones A/B de anuncios verticales (`1080×1920`, `-16 LUFS`, zona segura Reels/TikTok/Meta Ads) desde archivos JSON.
- 🌐 **Desarrollo Web Full Stack:** Plataformas de cotización multi-aseguradora, landing pages de conversión y herramientas operativas con **TypeScript, React 19, Vite y Tailwind CSS**.
